## 免费资源常见答疑 FAQ

### Q1：为什么网上那么多 Telegram 频道每天分享海量免费节点？
答：主要有三类目的：
1. **黑灰产引流洗白**：通过免费节点收集大量用户的访问数据与账号凭证；
2. **商业机场的诱饵试用**：先放几个极慢的限速节点引流，频道内再大量发布高额充值广告；
3. **恶意扫描肉鸡**：部分节点服务器已被黑客攻破，连接后你的设备会被作为代理肉鸡参与网络扫描。

### Q2：使用 Cloudflare WARP 会泄露我的真实 IP 吗？
答：不会。WARP 客户端与 Cloudflare 边缘服务器之间建立了完整的端到端 WireGuard 加密隧道，你本地运营商只能看到你与 Cloudflare 节点的加密 UDP 流量，无法知晓你的具体访问目标。

### Q3：如果我只是用来登录 GitHub 提交代码，有必要花钱买专线吗？
答：如果您仅需访问 GitHub 代码仓库，完全不需要花钱！可以通过配置 GitHub 官方学术镜像源，或在本地 Host 文件中绑定直连 IP，即可实现满速 `git clone` 与代码推送。但如果您需要使用 Copilot AI 自动补全功能，则建议配备原生纯净节点以防滥用阻断。
