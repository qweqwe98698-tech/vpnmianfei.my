## 第一章：跨境互联物理底座与网络拓扑解密

### 1.1 全球海底光缆与国际出口交换中心

很多人误以为“翻墙”只是某种纯软件算法，实际上，所有数据最终都必须通过真实的**物理玻璃纤维光缆**跨越国界与大洋。

* **核心海缆通道**：
  * **TPE（跨太平洋快速海缆）**：连接中国青岛、崇明到美国与台湾，设计容量大但常年高负载；
  * **APG（亚太网关海缆）**：连接上海、香港、日本、韩国、新加坡及马来西亚，是亚太近端低时延的核心动脉；
  * **NCP（新跨太平洋海缆）**：上海南汇直达美西俄勒冈，具备极高的单波长传输能力；
  * **SJC2（东南亚日本二号海缆）**：强化香港与新加坡两大国际互联网金融枢纽间的传输冗余。
* **陆地边境光缆**：
  * 主要经由深圳罗湖、落马洲口岸通往中国香港，是华南用户实现 20ms 超低时延的关键物理纽带。

### 1.2 自治系统（AS）、BGP 宣告与 Transit / Peering

互联网并非由单一机构运营，而是由数万个独立的**自治系统（Autonomous System, AS）**通过 **BGP（边界网关协议）** 相互路由。

```
[ 国内运营商 AS4134/AS4809 ] ──(商业 Transit 购买)──► [ 国际 Tier-1 骨干电信商 ]
                                                                 │
                                ┌────────────────────────────────┘
                                ▼ (海缆路由调度)
                 [ 目标落地机房 AS (如 Google AS15169 / Cloudflare AS13335) ]
```

* **Transit（转接）**：下游网络付费向更高级别的 Tier-1 运营商购买全球路由通达权；
* **Peering（对等互联）**：两个同级网络在互联网交换中心（IX，如香港 HKIX、东京 JPIX）免费或低成本直接交换本地流量。

普通中转机场往往在公网 Transit 环节遭遇严重的带宽瓶颈与 QoS 限速；而高端服务商则通过在香港、东京部署直连 HKIX/JPIX 的节点，实现极低抖动的数据直接交付。

## 第二章：公网中转 vs IPLC vs IEPL 终极物理架构对比

这是整个科学上网领域最核心的认知分水岭。我们通过底层数据链路拓扑图直观展示三者的本质差别：

### 2.1 拓扑架构差异图示

```
【架构 1：普通公网中转 (Public Relay)】
用户 ──(国内公网)──► 国内入口VPS ──(公共海缆公网出口 GFW严格审查与晚高峰QoS丢包)──► 境外落地VPS ──► 目标外网
  └─ 痛点：跨境段走公共互联网，晚高峰抢带宽丢包达 30%~60%，极易触发 GFW 阻断。

【架构 2：IPLC 国际私有租用线路 (International Private Leased Circuit)】
用户 ──(加密)──► 境内交换机 ======= (物理层 TDM 专有内网点对点物理光缆) =======> 境外机房 ──► 目标外网
  └─ 本质：Layer 1 物理光纤硬切片，根本不经过公网 GFW 网关，0 丢包，物理时延极低。

【架构 3：IEPL 国际以太网专线 (International Ethernet Private Line)】
用户 ──(加密)──► 境内PoP点 ======= (数据链路层 Layer 2 以太网封装专属隧道) ======> 境外PoP点 ──► 目标外网
  └─ 本质：新一代软件定义网络（SDN）弹性专线，兼具物理专线隔离度与动态扩容能力。
```

| **OSI 网络层级** | 应用层 / 传输层（Layer 4/7） | 物理层硬切片（Layer 1 TDM） | 数据链路层封装（Layer 2 Ethernet） |

## 第三章：2026 代理协议演进史：从特征明显到零感知伪装

当数据流在应用层封装时，采用什么协议直接决定了是否会被防火墙的深度包检测（DPI）主动嗅探并阻断。

### 3.1 协议演进代际谱系

```
第一代：明文与规则特征时代 (PPTP / L2TP / OpenVPN)
  └─ 缺点：协议握手特征极度明显，已被 GFW 机器学习模型秒级识别阻断。
        │
第二代：对称加密与混淆时代 (Shadowsocks / ShadowsocksR)
  └─ 优点：性能开销极低；缺点：重放攻击与主动探测导致公网直连极易封端口。
        │
第三代：伪装与证书伪造时代 (VMess / Trojan)
  └─ 突破：Trojan 伪装为标准 HTTPS 流量（443 端口），抗探测能力大幅跃升。
        │
第四代：新一代防嗅探与性能巅峰 (VLESS + XTLS/Reality / Hysteria 2 / TUIC)
  └─ 突破：去除冗余加密开销，Reality 实现借用真实知名网站证书抗探测；Hysteria2 基于 UDP 在恶劣弱网下暴力加速。
```

### 3.2 6 大主流现代代理协议全景技术参数横评表

| 协议名称 | 传输层基础 | 握手时延 | CPU 资源消耗 | 抗主动探测评级 | 适用网络环境与核心优缺点 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Shadowsocks (AEAD)** | TCP / UDP | 1-RTT | **极低**（适合低功耗设备）| 中等（依赖专线内网保护） | 搭配专线时体验极佳，延迟最低；但在恶劣公网直连时存在特征风险。 |
| **Trojan** | TCP + TLS | 2-RTT | 中等（标准 TLS 加密） | **极高**（伪装标准 HTTPS） | 将流量完美伪装成访问正规海外网站，只要域名证书完备几乎不被封。 |
| **VLESS + Reality** | TCP + 偷取证书 | 1-RTT | 低（无冗余自签名开销） | **天花板级**（借用真实大厂证书） | 彻底消灭证书自建成本与伪装漏洞，是当前 [光速云](/reviews/guangsu-cloud)、[微风网络](/reviews/weifeng-network) 的主推技术。 |
| **VMess + WS + TLS** | TCP + WebSocket | 3-RTT | 较高（双重加解密开销） | 高（可套 CDN 救砖） | 传统稳妥方案，但高握手延迟导致网页首屏响应略显拖沓。 |
| **Hysteria 2** | UDP (修改版 QUIC)| **0-RTT** | 中等（自研拥塞控制算法） | 高（伪造 UDP 端口） | 恶劣丢包弱网下的神级提速协议；但在部分严格 QoS 的运营商下 UDP 会被限速。 |
| **TUIC** | UDP (原生 QUIC) | **0-RTT** | 低（原生单路复用） | 高 | 头部握手开销极低，特别适合移动蜂窝网络下的即时通信与低延迟交互。 |

## 底层网络常见技术答疑 FAQ

### Q1：为什么专线机场的流量单价比普通中转贵一些？
答：因为物理机房成本有着本质差异。普通公网中转租用的是廉价的共享公网 IP 和超卖带宽；而 IEPL / IPLC 专线是电信运营商向企业客户出租的**物理内网端到端光纤**，按独占 Mbps 按月计费，机房成本刚性。为了一杯奶茶钱换取晚高峰 100% 不卡顿与 0 丢包，这种溢价对于专业办公用户极其划算。

### Q2：使用 VLESS Reality 还需要自己购买域名和配置证书吗？
答：不需要！这正是 Reality 技术的革命性所在。它通过“借用”海外正规大厂（如 Apple、Microsoft、Amazon）的真实有效证书完成 TLS 握手，省去了用户自购域名、配置 Let's Encrypt 证书以及证书过期维护的全部繁琐步骤，且由于证书真实存在于大厂服务器上，防火墙无法通过自签名证书特征进行识别阻断。

### Q3：为什么有些专线节点在测速软件里看延迟只有十几毫秒？
答：这是很多用户的误解。如果测速软件测试的是“用户 -> 境内前置入口交换机”的时延，显示的自然是华南或华东本地内网延迟（10~20ms）；真正的“端到端全链路延迟”必须包含境内入口到境外落地服务器的物理光纤传输时间。在光速云、微风网络的实测中，我们记录的是端到端真延迟（香港 22~25ms，日本 45~55ms，美西 130~150ms），这完全符合物理光速在玻璃纤维中的传输规律。
